# Engineering Rules

- Read before editing.
- Preserve working behaviour.
- One experiment = one clear question.
- Record expected vs actual behaviour.
- Measure before tuning.
- Simulate before applying aggressive control where practical.
- Verify sampling period and timing jitter.
- Keep safety limits explicit.
- Never treat reference code as automatically correct for the local hardware.
- Never hide uncertainty.
- Prefer small, reversible commits/changes.
- Build after meaningful source changes.
- Keep experimental code separate from stable firmware where practical.
- Explain why a controller works, not only what gain values to use.
